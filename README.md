# Heartbeat Widget

ווידג'ט אנדרואיד שמציג ספירה לאחור של פעימות הלב שנותרו ואחוז החיים שנשאר,
בהתבסס על תאריך לידה, דופק ממוצע ותוחלת חיים. מתעדכן כל שנייה כשהמסך דולק
ונעצר כשהמסך כבוי כדי לחסוך סוללה.

## איך בונים את ה-APK

1. מתקינים את **Android Studio** (חינמי) — https://developer.android.com/studio
2. פותחים את התיקייה `HeartbeatWidget` דרך `Open` באנדרואיד סטודיו.
3. אנדרואיד סטודיו יריץ Gradle Sync ויוריד לבד את מה שחסר (כולל ה-wrapper).
4. מחברים טלפון בכבל (עם USB debugging) או מפעילים אמולטור, ולוחצים **Run** (המשולש הירוק).
   - לחלופין, כדי לקבל קובץ APK להתקנה ידנית: `Build > Build Bundle(s) / APK(s) > Build APK(s)`.
     ה-APK ייווצר תחת `app/build/outputs/apk/debug/`.

## איך מוסיפים את הווידג'ט

לחיצה ארוכה על מסך הבית → Widgets → מוצאים את *Heartbeat Widget* → גוררים למסך.

אם המונה לא מתחיל לרוץ (בגלל מגבלות הרצה של אנדרואיד חדש), פותחים פעם אחת
את האפליקציה מרשימת האפליקציות — זה מפעיל את השירות.

## איך משנים הגדרות

כל ההגדרות בקובץ אחד:
`app/src/main/java/com/itzhak/heartbeatwidget/HeartbeatCalc.kt`

שם משנים תאריך לידה, שעה, דופק (`BPM`) ותוחלת חיים (`LIFE_EXPECTANCY_YEARS`).

## הערה על סוללה

השירות משתמש ב-Foreground Service, ולכן אנדרואיד מציג התראה קבועה ושקטה
שהוא פעיל — זו דרישת מערכת. הטיקר עצמו רץ רק כשהמסך דולק, אז הצריכה זניחה.
